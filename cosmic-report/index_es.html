Preguntas Frecuentes

¿Qué datos necesitas de mí?
Tu fecha de nacimiento completa, la hora exacta y el lugar de nacimiento. La hora es importante — determina tu signo ascendente y las cúspides de las casas. Si no sabes tu hora de nacimiento, podemos generar un informe parcial usando el amanecer como valor predeterminado, pero las posiciones de las casas y el signo ascendente serán aproximados.
¿Cómo se genera el informe?
El informe es generado por un motor Python que utiliza la biblioteca de Efemérides Suiza, calibrada contra los datos de efemérides NASA JPL DE440. La rueda de la carta se renderiza como un gráfico vectorial, y la narrativa se ensambla a partir de plantillas específicas para cada arquetipo generacional y signo ascendente. No se utiliza IA — cada palabra está escrita a mano.
