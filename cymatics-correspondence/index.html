About this Atlas

The Cymatic Correspondence Atlas is a navigable documentation view of the 4-axis data model in the cymatics archive.

The 4 axes

  • Frequency — Hz values, Solfeggio, planetary frequencies, the Fibonacci Hz series, the 12-note scale in A=440 and A=432
  • Form — Platonic solids, Chladni figures, sacred geometric patterns, Greek modes, ancient cosmic forms
  • Color — Newton 7, Goethe 12, planetary 7, Solfeggio 9, Cymascope mappings, Pythagorean/Culpeper correspondence
  • Planet — 7 classical planets + 3 modern, with their cross-axis correspondences (color, metal, day, form_solid, mode, chakra)

The data contract

This page is one consumer of the cymatics 4-axis data model. The same data (in Company_OS/notebook/cymatics/axes/*.json) is consumed by:

  • The static webapp (this page — the spiderweb rendered as HTML cards)
  • The Godot 3D cymatics visualization (the spiderweb rendered as a 3D scene with a vibrating plate)
  • Any agent queries against the cymatics archive (via the same cymatics_axes.py API in Python, mirrored as data.js in JavaScript)

Source provenance

Each card shows where the data came from. The data is drawn from:

  • Primary sources in Company_OS/notebook/cymatics/source_texts/ (Chladni 1787/1802/1817, Boethius, Iamblichus, Kepler, Hans Jenny Vol 2, Misseroni 2015)
  • Compiled dossiers in Company_OS/notebook/cymatics/sources/
  • Speculative sources quarantined in Company_OS/notebook/cymatics/_speculative_sources/ (flagged as unverified)

Epistemic standards

Not all data is equal. Cards and source links are marked with their epistemic status: primary, secondary, speculative, or unverified. The default is to verify before adopting.
