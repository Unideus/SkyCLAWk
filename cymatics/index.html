Provenance and Corrections

This page combines modeled acoustics, symbolic correspondences, and a few exploratory assumptions. The tags below show which is which so people can inspect the logic and suggest corrections.

Note and Pitch Readouts Physics

Frequency-to-note naming uses equal-tempered pitch math against the selected `A4` reference. This is musically standard labeling, not a special cymatics law.

Round Plate Modes Physics

The round view uses Bessel-zero mode families, which are mathematically grounded for circular standing-wave systems. In practice this is closer to a circular membrane model than a fully calibrated thin metal plate.

Square Plate Mapping Speculative

The square view maps frequency to pattern complexity heuristically. It is a useful visual ladder, but it is not yet tied to measured plate resonances, plate material, or support geometry.

Color Correspondence Correspondence

Audio frequency is octave-shifted into the visible range and converted to approximate spectral RGB. This is a symbolic octave analogy, not a confirmed physical rule of cymatics.

Solfeggio and Planetary Presets Correspondence

These presets come from tuning and esoteric correspondence traditions. They are included as exploratory reference sets, not as experimentally verified Chladni frequencies.

Cycle Modes Speculative

Cycle mode steps through generated mode families and inferred active frequencies so patterns can be explored continuously. It is not yet a measured resonance atlas from a real plate.
